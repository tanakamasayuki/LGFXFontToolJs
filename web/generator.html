1 Typeface

Is generating what you need?

LovyanGFX already ships with 186 fonts, and using one costs no flash for glyph data at all. Generate here when you want a size or a typeface the presets do not have, or when you want to pay flash for only the characters you actually use.

Browse the built-in fonts in the Viewer →

Only SIL OFL 1.1 and Apache-2.0 families are listed — both allow the generated glyph data to be embedded in and shipped with your firmware (with attribution, which the generated header carries).

Check the licence before you use this.

Generating an embedded font converts the typeface's glyphs into data that ships inside your firmware — that is redistribution. Many fonts, including most commercial fonts and the ones bundled with Windows, macOS and Office, do not permit it. Only use a file here if its licence explicitly allows embedding and redistribution.

2 Size & name

The size is the character height in pixels — the ink height of a reference glyph (an ideograph for CJK-capable fonts, a capital otherwise), so "24" looks the same size in every typeface. The line height is derived from the glyphs and reported next to the preview. Output is 1bpp: the threshold decides how much anti-aliased coverage counts as "on"; lowering it makes the font heavier.
